# バグ修正計画 (Tasks for Bug Fixes)

このドキュメントは、`pickit` プロジェクトにおける不具合修正の進捗を管理します。機能追加については `plan.md` を参照してください。

---

## 完了済みの課題

### 課題/不具合 #2 - TUI表示色の修正
- **説明:** チェックアウト情報がないディレクトリが不当に白色で表示されていた問題を修正。
- **対応:** `update_tree_item_states` のロジックを修正し、明示的/暗黙的なチェックアウト状態、および子孫の状態を正確に反映するように変更。テストケース `test_tui_item_styles` を追加して検証済み。
- **ステータス:** 完了

### 課題/不具合 #3 - キー応答遅延と手動リフレッシュ
- **説明:** 大規模リポジトリでの遅延解消のため、自動監視を廃止。
- **対応:** `notify` 依存関係を削除し、`r` キーによる手動リフレッシュ機能を実装。`git status` チェックを1回に集約して高速化。
- **ステータス:** 完了

### 課題/不具合 #4 - 未ロードノード選択時のチェックアウト漏れ
- **説明:** 展開前のノードを選択して適用した際に Git コマンドに反映されない問題を修正。
- **ステータス:** 完了

### 課題/不具合 #10 - 日本語ファイル名対応
- **説明:** 日本語を含むパスの文字化けや操作失敗を解消。
- **対応:** `LANG=C.UTF-8` 設定の強制、内部パスの純粋UTF-8管理、および日本語パスを含むテストスイートの拡充により対応。
- **ステータス:** 完了
